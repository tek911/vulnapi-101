SAFE

API1:2023

Broken Object Level Authorization (BOLA)

APIs expose endpoints that handle object identifiers, creating attack surfaces for IDOR vulnerabilities.

CRITICAL

API2:2023

Broken Authentication

Authentication mechanisms implemented incorrectly, allowing credential stuffing, brute force, and token theft.

CRITICAL

API3:2023

Broken Object Property Level Authorization

Lack of proper authorization at the property level leads to data exposure and mass assignment.

HIGH

API4:2023

Unrestricted Resource Consumption

APIs without rate limiting or resource controls vulnerable to DoS and resource exhaustion.

MEDIUM

API5:2023

Broken Function Level Authorization (BFLA)

Administrative functions accessible without proper role verification.

HIGH

API6:2023

Unrestricted Access to Sensitive Business Flows

Business logic vulnerabilities allowing abuse of workflows and automated attacks.

MEDIUM

API7:2023

Server Side Request Forgery (SSRF)

APIs fetching remote resources without proper URL validation.

HIGH

API8:2023

Security Misconfiguration

Debug mode, verbose errors, unnecessary features, and missing security hardening.

CRITICAL

API9:2023

Improper Inventory Management

Undocumented endpoints, deprecated APIs, and lack of proper API documentation.

MEDIUM

API10:2023

Unsafe Consumption of APIs

Trusting data from third-party APIs without proper validation.

MEDIUM
